# Content model

- `settings`: site name, region, contact details, prices, default venue, map settings.
- `series`: recurring dances and classes.
- `events`: one-off events and overrides for one series date.
- `venues`: addresses, coordinates, parking and accessibility notes.
- `organizers`: community groups that run listed events.
- `instructors` and `performers`: teachers, DJs, and bands.
- `styles`, `faqs`, `pages`, `announcements`, `gallery`: supporting site content.

Home events use `host: home`; community listings use `host: community` and should include an organizer and source.
